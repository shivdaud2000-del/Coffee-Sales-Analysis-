# ☕ Coffee Sales Analysis | EDA + Power BI Dashboard

----------------------------------------------------------------------------------------------

# 📌 Project Overview

This project focuses on analyzing coffee sales data using Python for Exploratory Data Analysis (EDA) and Power BI for interactive dashboard visualization. The analysis uncovers valuable insights related to customer purchasing behavior, sales performance, product demand, and time-based revenue trends.

Using data analysis and visualization techniques, this project helps businesses understand customer preferences and make data-driven business decisions.

--------------------------------------------------------------------------------------------

# 🎯 Project Objectives

✅ Analyze overall coffee sales performance  

✅ Identify top-selling coffee products  

✅ Understand customer purchasing patterns  

✅ Discover hourly, daily, and monthly sales trends  

✅ Compare revenue across coffee categories  

✅ Generate meaningful business insights using interactive dashboards

# 📈 Key Insights

✔ Total Revenue Generated: **112.25K**  

✔ Total Orders Completed: **4K**  

✔ Average Order Value: **31.65**  

✔ Latte generated the highest revenue among all coffee categories  

✔ Americano and Cappuccino were also strong revenue contributors  

✔ Sales were highest during Morning and Afternoon time periods  

✔ Peak order hours were between **10 AM – 2 PM**  

✔ Tuesday generated the highest revenue among weekdays  

✔ March and November showed slightly higher monthly revenue trends  

✔ Daily revenue remained stable between **2K–5K**, indicating consistent customer demand
